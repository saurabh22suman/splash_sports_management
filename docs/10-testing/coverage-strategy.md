# Coverage Strategy

> Coverage is a sanity check, not a goal. We target specific coverage levels for different code layers, focus on what matters (logic, branches, error paths), and explicitly avoid covering generated code or trivial getters.

This document covers our coverage strategy: per-layer targets, what to cover, what NOT to cover, branch vs. line coverage, and CI gates. These targets ensure we test what matters without chasing meaningless percentages.

---

## Coverage Targets by Layer

| Layer | Target | Minimum |
|-------|--------|---------|
| Domain (entities, value objects) | 95% | 90% |
| Services (application logic) | 90% | 85% |
| API (routers, schemas) | 80% | 70% |
| Infrastructure (repositories) | 70% | 60% |
| Overall | 85% | 75% |

> **Rule** — Coverage targets are enforced in CI. PRs below minimum fail.

## What to Cover

### Business Logic

```python
# MUST COVER - business rules
class PricingService:
    def calculate_total(self, facility, duration, member_tier):
        # Core business logic - COVER THIS
        base = facility.hourly_rate * (duration / 60)

        # Branch: member discount
        if member_tier == "premium":
            discount = 0.20
        elif member_tier == "standard":
            discount = 0.10
        else:
            discount = 0

        return base * (1 - discount)
```

### Branches

```python
# MUST COVER - all branches
def is_available(booking, existing_bookings):
    # Branch 1: no existing bookings
    if not existing_bookings:
        return True

    # Branch 2: no overlap
    for existing in existing_bookings:
        if not self._has_overlap(booking, existing):
            return True

    # Branch 3: overlap found
    return False
```

### Error Paths

```python
# MUST COVER - error handling
def create_booking(self, request):
    try:
        # Happy path
        facility = self.repository.get_facility(request.facility_id)
        if not facility:  # Error path
            raise FacilityNotFoundError(...)

        # More code...

    except DatabaseError as e:  # Error path
        logger.error(f"Database error: {e}")
        raise BookingServiceError(...)
```

## What NOT to Cover

### Generated Code

```python
# DON'T COVER - generated by framework
from pydantic import BaseModel


class BookingSchema(BaseModel):
    # Generated by pydantic - skip
    id: str
    facility_id: str
```

### Trivial Getters

```python
# DON'T COVER - trivial accessors
class Booking:
    @property
    def id(self):
        return self._id  # Trivial - no logic

    @property
    def status(self):
        return self._status  # Trivial - no logic
```

### Configuration

```python
# DON'T COVER - constants
class Config:
    MAX_BOOKING_DURATION = 120  # Just a constant
    CANCELLATION_WINDOW_HOURS = 24  # Just a constant
```

### Test Fixtures

```python
# DON'T COVER - test utilities
def create_test_booking():
    # Test fixture, not production code
    return Booking(...)
```

## Line vs. Branch Coverage

### Line Coverage

```python
# Line coverage: are lines executed?
def process(amount):
    if amount > 0:      # Line 1 - covered
        return amount   # Line 2 - covered if amount > 0
    return 0            # Line 3 - covered if amount <= 0
```

### Branch Coverage

```python
# Branch coverage: are branches tested?
def process(amount):
    if amount > 0:        # Branch A (true) - need test with amount=10
        return amount     # Branch B (false) - need test with amount=-10
    return 0
```

> **Why** — Line coverage can be 100% while missing branches. We require branch coverage for critical paths.

## Configuration

### pytest-cov Setup

```ini
# pytest.ini
[tool:pytest]
addopts =
    --cov=apps/backend/src
    --cov-report=term-missing
    --cov-report=html
    --cov-fail-under=85
    --cov-branch
```

### Excluding Code

```python
# .coveragerc
[run]
source = apps/backend/src
branch = True

[report]
exclude_lines =
    # Don't report on these
    if TYPE_CHECKING:
    @abstractmethod
    @abc.abstractmethod
    raise NotImplementedError

omit =
    # Don't cover these
    */tests/*
    */migrations/*
    */__pycache__/*
    */conftest.py
    */generated/*
```

## Coverage Anti-patterns

### 1. Coverage as Goal

```python
# BAD: Chasing 100% coverage
def test_trivial_getter():
    # Just to increase coverage
    assert booking.id == "123"  # Waste of time
```

> **Anti-pattern** — Coverage >90% is diminishing returns. Focus on critical paths.

### 2. No Error Path Coverage

```python
# BAD: Only covering happy path
def test_create_booking():
    booking = service.create_booking(...)
    assert booking  # What about error cases?
```

> **Anti-pattern** — Error paths are where bugs hide.

### 3. Excluding Core Code

```python
# BAD: Excluding business logic from coverage
[report]
omit =
    */booking/service*  # But that's what we need to cover!
```

> **Anti-pattern** — Excluding critical code defeats the purpose.
